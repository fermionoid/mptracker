MP Tracker 是什么？

胜任感（M）× 愉悦感（P）= 行为强化的两个关键维度

原理（简版）
记录每次任务完成后的 胜任感（Mastery）与 愉悦感（Pleasure）。 长期来看，你会更清楚：哪些活动“做得来”、哪些活动“做着爽”，从而更容易形成稳定习惯。
怎么用
  1. 点 Start 开始任务；结束后点 Stop。
  2. 复盘里给 M/P 打分（1-5）。越随手越好。
  3. 默认 保存；需要的话点 AI 分析 给一句洞察。
  4. 历史里可直接点任务名 / 分类 / M / P 进行就地编辑。
